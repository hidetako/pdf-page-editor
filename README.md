# PDF Page Editor

Windows 向けの軽量 PDF ビューア + ページ編集 + 電子印鑑ツール。1 つの画面で「見る」「ページ構成を直す」「押印して保存」ができる。

## 機能
- PDF 表示（全ページを縦に並べた連続スクロール。幅合わせ / ズーム 50〜300% / Ctrl+ホイール、PgUp/PgDn でページ移動。表示中のページがサムネイルで選択される）
- サムネイル一覧をドラッグ&ドロップで並べ替え（複数選択可）
- 回転（左右 90°）、削除、前後移動
- 他の PDF・画像（PNG/JPG/TIFF など）をページとして挿入（選択ページの後ろ）
- 選択ページだけを別 PDF として抽出
- 元に戻す / やり直し（20 段階）
- 保存（上書き）/ 名前を付けて保存。一時ファイル経由のアトミック書き込み
- ウィンドウへのファイルドロップで開く / 追加
- 自動アップデート（インストール版）。起動時に GitHub Releases の新しい版を確認し、「更新する」でダウンロード→インストール→再起動。「ヘルプ > 起動時に更新を確認」で OFF にできる。更新は今動いている exe と同じ場所（ユーザー用 / 全ユーザー用）に上書きされる
- 印刷（Ctrl+P）。すべて / 現在のページ / 選択ページ / 範囲指定、部数、用紙に合わせて拡大縮小。横長ページは自動で回転
- パスワード付き PDF。開くときに入力を求め、保存時は同じパスワードで暗号化し直す（AES-256）。「ファイル > パスワードを設定・解除」で付け外しできる。挿入する PDF がパスワード付きの場合も入力を求める。閲覧パスワード無しで印刷・編集などが禁止された PDF は開けるが、保存すると制限は外れる（開いたときに知らせる）
- 書き込み（「書き込み」ボタンまたは F4 でリボンを表示。Esc で道具を「選択」に戻し、もう一度 Esc で閉じる）
  - ペン（手書き）、直線、矢印、四角、丸をドラッグで描く。色（6 色＋任意の色）、太さ、濃さ、塗りつぶしを選べる。「太さ=マーカー、濃さ=50%」で手書きの蛍光ペンになる
  - 文字: クリックした場所に書き込む。フォント、大きさ、背景（なし / 白 / 黄）、枠を選べる。背景を白にすると、下の文字を隠して上書きしたように見せられる（下の文字そのものは PDF に残る）
  - フォントは「標準ゴシック」（内蔵）のほか、PC に入っている TrueType のゴシック系（メイリオ、メイリオ 太字、游ゴシック、BIZ UDゴシック、MS ゴシック）。使った文字だけを PDF に埋め込むので、どのソフト・どの PC で開いても同じ見た目になる（1 か所あたり約 10 KB）。埋め込めないフォントは一覧に出ない
  - 蛍光ペン（Ctrl+Shift+H）/ 下線（Ctrl+Shift+U）/ 取り消し線（Ctrl+Shift+K）は、ドラッグで選んだ文字に付ける
  - 書いたものはクリックで選び、ドラッグで移動、右下の四角をドラッグで大きさ変更、Delete キーで削除。選択中にリボンの色・太さ・フォントなどを変えると、その書き込みに反映される。文字はダブルクリックで直せる。右クリックからも編集・色変更・削除ができる
  - 他のソフトで付けた注釈も同じように選んで移動・色変更・削除ができる。蛍光ペンなど文字に付く注釈は移動できない
  - すべて PDF 標準の注釈として保存され、Acrobat 等でも見える。書き込みはいつでも Ctrl+Z で戻せる

未対応: 本文テキストの編集（PDF には文字の流し直しという概念が無く、別の仕組みが必要）。

### 閲覧の補助（表示モード・目次・しおり・付箋）
- 表示モード（メニュー「表示 → 表示モード」）: ノーマル（白地）／暖色（薄いクリーム色 #FAF0DC）／白黒反転。選択は次回起動時に復元
- 目次・しおりパネル（F9）: PDF に目次（索引・アウトライン）があれば自動で左に開き、クリックでそのページへ移動。自動で開くかは「しおり・付箋」メニューで切替
- しおり: 「現在ページをしおりに追加」（Ctrl+D）で目次に追加。名前変更・削除も可。PDF のアウトラインとして保存されるので他のビューアでも見える
- 付箋（F3）: 付箋モードでページをクリックするとメモ（テキスト注釈）を貼る。マウスを乗せると内容を表示、右クリックで編集・削除。PDF の注釈として保存され、Acrobat 等でも開ける。Ctrl+Z で取り消し可
- 押印モードに入ると電子印鑑パネルが自動で開く
- 押印・付箋・書き込みは排他（1 つに入ると他は解除）。Esc でいずれも終了
- テキスト選択・コピー: 通常モードでページ上をドラッグすると文字を選択（青く強調）。Ctrl+C または右クリック「コピー」でクリップボードへ。文字の上では I ビームカーソル。Esc か余白クリックで解除

### 追加のインポート経路
- 「インポート」は JSON / .entstmp のほか、印影画像（PNG/JPG/BMP/GIF/TIFF/WebP、複数可）も受け付け、画像印として登録する。印鑑一覧へのドラッグ&ドロップでも可
- アプリアイコン: `assets/icon.ico` / `assets/icon.png`（赤い角丸四角に白いリボン状の A。独自デザイン）。ウィンドウ・タスクバー・exe に適用

## 動作環境
- Windows 10 / 11 (64bit)、Python 3.10 以上（exe 化後は Python 不要）
- ライブラリ: PyMuPDF (AGPL-3.0)、PySide6 (LGPL-3.0)

## 押印の手順
1. 右側「電子印鑑」パネルで印鑑を選ぶ（「新規」「編集」で文字や大きさを変更）
2. 「押印モード」ボタン（または F2）を押す
3. ページ上の押したい位置をクリック。続けて何か所でも押せる。Esc で終了
4. 「保存」。押印を取り消すには、印影を右クリック →「この押印を取り消す」（または Ctrl+Z で直前の操作を戻す）

## 他ソフトの印影を取り込む
「おまかせ電子印鑑 for Business」でエクスポートした `.entstmp` は、印鑑パネルの「インポート」からそのまま読み込める（複数選択可）。大きさの情報は含まれていないので 15 mm で登録される。「編集」で直径や名前を直す。

## インストール（Windows、ダウンロードして実行するだけ）
1. [Releases](https://github.com/hidetako/pdf-page-editor/releases) から `PdfPageEditor-Setup-x.y.z.exe` をダウンロード
2. ダブルクリックして「次へ」。管理者権限は不要（ユーザー領域にインストールされる）
3. スタートメニューの「PDF Page Editor」から起動。エクスプローラーで PDF を右クリック →「プログラムから開く」にも出る

未署名のため SmartScreen の警告が出る。「詳細情報」→「実行」で進める。
アンインストールは Windows の「アプリと機能」から。印鑑データは `%APPDATA%\PdfPageEditor\stamps.json` に残る。

## 使い方（ソースから）
1. このフォルダを `C:\dev\pdf-page-editor` などに置く
2. `run.bat` をダブルクリック（初回は仮想環境作成とライブラリ取得で数分）

## exe・インストーラーを自分で作る
- ローカル: `build_windows.bat` をダブルクリック。`dist\PdfPageEditor.exe` ができ、Inno Setup 6 が入っていれば `dist\PdfPageEditor-Setup-x.y.z.exe` も作られる
- GitHub Actions: `app.py` の `__version__` を上げて `main` にマージすると、`.github/workflows/release.yml` が Linux で全テスト（E2E 含む）を実行し、Windows でビルドして、タグ `vX.Y.Z` を打って Releases に公開する（同じバージョンのタグがすでにあればビルドのみ）
- PyMuPDF 2.x は起動時にレイアウト解析モデルを読み込もうとするため、そのまま PyInstaller にかけると `layout_rf*.yaml` が見つからず起動に失敗する。本アプリでは不要なので `--exclude-module pymupdf.layout` 等で除外している（bat と workflow に設定済み。同梱したい場合は代わりに `--collect-data pymupdf` を付ける）


## 構成
- `pdfmodel.py` : PyMuPDF をラップした編集ロジック（Qt 非依存、単体テスト可）
- `stamps.py`   : 印影の定義・描画・ライブラリ保存（Qt 非依存）
- `stamp_ui.py` : 印鑑パネルと印鑑編集ダイアログ
- `fonts.py`    : 書き込み用フォントの検出と、埋め込みフォントでの文字の描画（Qt 非依存）
- `write_ui.py` : 書き込みリボン（道具・色・太さ・フォントなど）
- `selftest.py` : 配布用 exe の自己診断（`PdfPageEditor.exe --selftest 記録ファイル`。CI がビルド後に実行し、失敗したら公開しない）
- `app.py`      : PySide6 GUI 本体
- `installer/PdfPageEditor.iss` : Inno Setup のインストーラー定義
- `updater.py`   : 自動アップデート（GitHub Releases の確認とダウンロード、Qt 非依存）
- `tests/test_model.py`, `tests/test_stamps.py`, `tests/test_notes_toc.py`, `tests/test_updater.py`, `tests/test_write.py` : 自動テスト（直接実行）
- `tests/test_e2e_gui.py` : GUI の E2E テスト（オフスクリーンで実際の画面を操作。`E2E_SHOTS=出力先` で各段階のスクリーンショットを保存）
